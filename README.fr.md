# RyvieOS

[English](README.md) · **Français**

> Fait partie de l'écosystème [Ryvie](https://github.com/ryvieos/Ryvie), l'OS de cloud personnel auto-hébergé. Plus d'infos sur [ryvie.fr](https://ryvie.fr).

RyvieOS est le système d'exploitation qui transforme un VPS ou une machine physique en un cloud personnel auto-hébergé. Il fournit la couche de base qui fait tourner toute la stack Ryvie, pour héberger vos propres applications, fichiers et services sur du matériel que vous contrôlez. Que vous montiez un serveur maison (home server) ou que vous repreniez la main sur vos données, RyvieOS vous offre un cloud personnel privé qui vous appartient de bout en bout.

## Installation

Installez RyvieOS avec une seule commande :

```bash
curl -fsSL https://raw.githubusercontent.com/maisonnavejul/RyvieOS/tst/install.sh | bash
```

## Ce qu'il inclut

- **App store en un clic** — parcourez et déployez des applications auto-hébergées en un seul clic.
- **SSO centralisé** — une seule identité et une seule connexion pour toutes les applications de votre cloud personnel.
- **Stockage RAID géré** — un stockage mutualisé et redondant qui protège vos données.
- **VPN intégré** — accédez à votre serveur maison en toute sécurité depuis n'importe où.
- **Passerelle IA privée** — utilisez des fonctionnalités d'IA via votre propre passerelle, selon vos règles.

## Prérequis

- Processeur 4 cœurs
- 8 Go de RAM minimum
- 50 Go de stockage
