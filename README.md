# RyvieOS

**English** · [Français](README.fr.md)

> Part of the [Ryvie](https://github.com/ryvieos/Ryvie) ecosystem, the self-hosted personal cloud OS. Learn more at [ryvie.fr](https://ryvie.fr).

RyvieOS is the operating system that turns a VPS or a physical machine into a self-hosted personal cloud. It provides the base layer that runs the full Ryvie stack, so you can host your own apps, files, and services on hardware you control. Whether you are building a home server or reclaiming your data from big providers, RyvieOS gives you a private personal cloud that is yours end to end.

## Installation

Install RyvieOS with a single command:

```bash
curl -fsSL https://raw.githubusercontent.com/maisonnavejul/RyvieOS/main/install.sh | bash
```

## What it includes

- **One-click app store** — browse and deploy self-hosted apps in a single click.
- **Centralized SSO** — one identity and one login across every app on your personal cloud.
- **Managed RAID storage** — pooled, redundant storage that keeps your data safe.
- **Built-in VPN** — reach your home server securely from anywhere.
- **Private AI gateway** — run AI features through your own gateway, on your terms.

## Requirements

- 4-core CPU
- 8 GB RAM minimum
- 50 GB storage
